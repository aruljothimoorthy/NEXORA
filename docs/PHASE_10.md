# Phase 10 — Production deployment

Live deploy needs **your** cloud accounts. Configs in this repo are ready; complete the steps below in order.

## Prerequisites

- [ ] Repo pushed to GitHub (see [GITHUB_SETUP.md](./GITHUB_SETUP.md))
- [ ] MongoDB Atlas account
- [ ] Render account (linked to GitHub)
- [ ] Vercel account (linked to GitHub)

---

## Step 1 — MongoDB Atlas

1. Create a **M0 free** cluster.
2. **Database Access** → Add user → save username/password.
3. **Network Access** → Add IP → `0.0.0.0/0` (allow Render).
4. **Connect** → Drivers → copy URI, replace `<password>`, set DB name to `nexora`:

```text
mongodb+srv://USER:PASS@cluster0.XXXX.mongodb.net/nexora?retryWrites=true&w=majority
```

Keep this URI for Render (`MONGODB_URI`).

---

## Step 2 — Backend (Render)

1. [Render Dashboard](https://dashboard.render.com) → **New** → **Blueprint**.
2. Select the `nexora` GitHub repo (root `render.yaml`).
3. When prompted, set:

| Key | Value |
|-----|--------|
| `MONGODB_URI` | Atlas URI from Step 1 |
| `CLIENT_URL` | Leave a placeholder for now, e.g. `https://placeholder.vercel.app` — update after Step 3 |

`JWT_SECRET` is auto-generated by the Blueprint.

4. Wait for deploy → open:

```text
https://nexora-api.onrender.com/api/health
```

(Exact host is shown on the Render service page.)

Expect `"database": "connected"`. First free-tier boot can take ~1 minute.

---

## Step 3 — Frontend (Vercel)

1. [Vercel](https://vercel.com/new) → Import `nexora` repo.
2. **Root Directory:** `frontend`
3. Environment Variable:

| Key | Value |
|-----|--------|
| `VITE_API_URL` | `https://YOUR-RENDER-HOST.onrender.com/api` |

4. Deploy → copy the production URL (e.g. `https://nexora-xxxx.vercel.app`).

---

## Step 4 — Wire CORS

Back on Render → `nexora-api` → Environment:

| Key | Value |
|-----|--------|
| `CLIENT_URL` | your Vercel URL (no trailing slash) |
| `COOKIE_SECURE` | `true` |
| `NODE_ENV` | `production` |
| `USE_MEMORY_MONGO` | `false` |

**Manual Deploy** so CORS picks up the real frontend origin.

---

## Step 5 — Verify

From the repo root:

```bash
set NEXORA_API_URL=https://YOUR-RENDER-HOST.onrender.com
set NEXORA_CLIENT_URL=https://YOUR-APP.vercel.app
node scripts/verify-production.mjs
```

Then in the browser:

- [ ] Register / login
- [ ] Seed demo or create a project
- [ ] Drag a Kanban card
- [ ] Comment + notification
- [ ] Profile / settings / theme
